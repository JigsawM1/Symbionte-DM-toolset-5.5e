# Variante: Puntos de Conjuro

> [!info] Sistema de Magia Alternativo
> Tablas de conversión y progresión para usar Puntos de Conjuro en lugar de los clásicos espacios de conjuro. Este sistema otorga mucha más flexibilidad y es la base perfecta para integrar mecánicas caseras, como un sistema de sobrecarga para el [[Hechicero]].
